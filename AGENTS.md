# BRS Mobile Application

## Overview

BRS is a project-based accounting and construction management platform.

The mobile application is a client for the BRS FastAPI backend.

The backend is the source of truth for:

- Accounting rules
- Voucher numbering
- Ledger generation
- Fiscal year logic
- Project accounting
- Party accounting

Frontend is responsible only for:

- Data entry
- Validation
- Visualization
- Workflow guidance

## Accounting Principles

BRS follows double-entry accounting.

Every voucher must remain balanced.

Debit Total = Credit Total

Validation occurs on backend.

---

## Voucher Numbering

Voucher numbers are generated by backend.

Frontend must never generate:

- Voucher numbers
- Fiscal sequences
- Ledger codes

Frontend displays returned values only.

---

## Fiscal Year Rules

Voucher numbering is fiscal-year scoped.

Example:

RV-2082-00001
PV-2082-00001
JV-2082-00001

Generated by backend only.

---

## Ledger Rules

Every voucher affects ledger balances.

Ledger posting occurs on backend.

Frontend must not simulate posting logic.

---

## Mobile Development Goal
